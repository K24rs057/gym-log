# gym-log

ジムの筋トレを記録して、今日のメニューを教えてくれるスマホ向けのWebアプリ。

## できること
- **今日のメニュー**: 「胸+肩」と「背中+腕」の2日を順番に回す。休みの日は入れず、行けなかったら「続きから」。今日のおすすめには「今日」の印が付く。
- **固定の種目**: 胸+肩は ベンチプレス / インクラインチェストプレス / ベンチプレス(スミス) / ショルダープレス、背中+腕は ラッドプルダウン / 懸垂 / ケーブルプレスダウン / バイセップスカール。SETTINGS の MENU ITEMS で日ごとに変えられる。
- **腹と脚**: ジムに行った日を数えて、3回ごとに腹(アブドミナル)、5回ごとにレッグエクステンションを、その日の最後に足す。
- **前回と目標**: 前回のセットを見せて、1セット目が目標回数(初期10回)に届いていたら、目標の重量を1刻み上げる。
- **さぼり日数**: 前回から空いた日数を表示する。7日以上は目立つ色。
- **通知**: 最後の記録から3日たつと、ntfy で1回だけ知らせる。
- **できなかった種目**: 「今日はやらない」でスキップ。セットは「✕」で削除できる。
- **履歴**: 種目ごとの重量の推移を、日単位のグラフで見る(初期は1週間、拡大・縮小できる)。

## 使い方
1. `lab/products/gym-log/` を無料の静的ホスティングで公開し、スマホで開いてホーム画面に追加する。
2. 過去の記録を入れるとき: `python tools/import_memo.py` で `data/gym-log-import.json` を作り、スマホに送って SETTINGS の「読み込む」で選ぶ。
3. 通知: スマホに ntfy アプリを入れ、SETTINGS の「名前を作る」で出たトピック名を購読する。「テスト通知」で届くか確認できる。

## 保存
記録はスマホのブラウザ内(localStorage)にだけある。SETTINGS の「書き出す」でときどきバックアップする。

## ファイル
- `index.html` / `app.js` / `styles.css` … アプリ本体
- `manifest.webmanifest` / `sw.js` / `icon.svg` … ホーム画面に追加・圏外で開く用
- `tools/import_memo.py` … ジムのメモ(`data/raw_memo.txt`)を読み込み用ファイルに整える
- `data/` … 個人の記録。コミットしない

## メモの取り込みルール
- 種目名のゆれ(RADプルダウン / プルダウン → ラッドプルダウン、シーテッドロー → ロー など)は統一する。
- 判断がつかない行は `data/import_review.md` に出る。

## 公開するときの注意
`data/` は公開しない。公開するのは `index.html` `app.js` `styles.css` `manifest.webmanifest` `sw.js` `icon.svg` だけ。
